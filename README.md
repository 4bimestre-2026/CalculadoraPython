# Calculadora Python

Uma calculadora simples desenvolvida em Python utilizando a biblioteca Tkinter, com o objetivo de praticar lógica de programação, funções e criação de interfaces gráficas.

## Funcionalidades

Adição (+)

Subtração (-)

Multiplicação (x)

Divisão (÷)

Limpar visor

Apagar último caractere

Números decimais

## Tecnologias

Python

Tkinter
